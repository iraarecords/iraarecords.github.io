プライバシーポリシー

IRAA uploader（YouTube チャンネル「国際遺物管理機構」の制作用ツール）

1. YouTube API サービスの利用

このツールは YouTube API サービスを使用しています。このツールを使用する場合は、YouTube 利用規約に同意したものとみなされます。Google による情報の取り扱いは Google プライバシーポリシーをご覧ください。

2. 取得する情報

このツールは、チャンネルの運営者本人が Google アカウントで許可した範囲で、次の情報を取得します。

  • 運営者自身の YouTube チャンネルの情報（チャンネル名・登録者数など）
  • 運営者自身のチャンネルの動画・再生リスト・コメント
  • 運営者自身のチャンネルの YouTube アナリティクスの数値（再生数・視聴時間など）
  • Google が発行するログイン用の情報（アクセストークン・リフレッシュトークン）

運営者以外の方の個人情報を集める目的はありません。コメントの内容など、運営者のチャンネル上にある他の方の情報は、チャンネルの管理（コメントへの返信・不適切なコメントの対応）にのみ使用します。

3. 情報の使い方

取得した情報は、運営者自身のチャンネルへの動画の投稿と管理、および運営者自身のチャンネルの状況の確認にのみ使用します。広告への利用、販売、第三者への提供は行いません。

4. 保存と削除

取得した情報とログイン用の情報は、運営者のパソコンの中の、運営者だけが読める場所にのみ保存します。外部のサーバーには保存しません。YouTube API サービスの開発者ポリシーに従って扱い、不要になった情報は削除します。

5. クッキーなど

このツールとこのウェブサイトは、クッキーやそれに類する仕組みを使用しません。なお、このウェブサイトは GitHub Pages で公開しており、アクセスの記録は GitHub の方針に従って扱われます。

6. 許可の取り消し

このツールに与えた許可は、Google アカウントのセキュリティ設定（サードパーティのアクセス）から、いつでも取り消せます。

Privacy Policy

IRAA uploader (a production tool for the YouTube channel “国際遺物管理機構”)

1. Use of YouTube API Services

This tool uses YouTube API Services. By using this tool, you agree to be bound by the YouTube Terms of Service. For how Google handles information, see the Google Privacy Policy.

2. Information we access

Within the scope authorized by the channel owner through their Google account, this tool accesses:

  • information about the owner’s own YouTube channel (such as channel name and subscriber count);
  • videos, playlists and comments on the owner’s own channel;
  • YouTube Analytics metrics for the owner’s own channel (such as views and watch time);
  • sign-in credentials issued by Google (access token and refresh token).

The tool does not aim to collect personal information about anyone other than the owner. Information about other people that appears on the owner’s channel, such as comments, is used only to manage the channel (replying to comments and handling inappropriate ones).

3. How we use information

Information is used only to upload and manage videos on the owner’s own channel and to review the channel’s performance. It is not used for advertising, sold, or shared with third parties.

4. Storage and deletion

Information and credentials are stored only on the owner’s computer, in a location readable only by the owner. Nothing is stored on external servers. Data is handled in accordance with the YouTube API Services Developer Policies and deleted when no longer needed.

5. Cookies

Neither this tool nor this website uses cookies or similar technologies. This website is hosted on GitHub Pages, and access logs are handled under GitHub’s policies.

6. Revoking access

You can revoke this tool’s access at any time from the Google security settings (third-party access) page.
