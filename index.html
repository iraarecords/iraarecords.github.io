IRAA uploader

YouTube チャンネル「国際遺物管理機構」の制作用ツール

YouTube チャンネル「国際遺物管理機構」（@IRAA_records404）は、架空の発掘調査記録を描くフィクション（モキュメンタリー）のチャンネルです。国際遺物管理機構（IRAA）は実在しない架空の組織で、実在の団体・研究機関とは関係ありません。

このツールについて

IRAA uploader は、チャンネルの運営者が自分のパソコンで使う、運営者専用のツールです。YouTube API サービスを使って、次のことを行います。

  • 運営者自身のチャンネルへの動画のアップロードと、タイトル・説明・サムネイル・公開日時の設定
  • 運営者自身のチャンネルの再生リストとコメントの管理
  • 運営者自身のチャンネルの再生数・視聴時間などの確認（YouTube アナリティクス）

このツールは一般には公開しておらず、運営者以外は使用しません。

IRAA uploader

A production tool for the YouTube channel “国際遺物管理機構” (IRAA)

The YouTube channel “国際遺物管理機構” (@IRAA_records404) is a fiction (mockumentary) channel about imaginary archaeological records. IRAA is a fictional organization and is not affiliated with any real organization or research institution.

About this tool

IRAA uploader is a private tool used only by the channel owner on their own computer. It uses YouTube API Services to:

  • upload videos to the owner’s own channel and set titles, descriptions, thumbnails and scheduled publish times;
  • manage playlists and comments on the owner’s own channel;
  • read views, watch time and other YouTube Analytics data for the owner’s own channel.

The tool is not offered to the public and is used by no one other than the channel owner.
